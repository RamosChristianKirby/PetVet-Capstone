# PetVet web workspace

See [the project guide](../ReadMe.md) for setup, demo accounts, configuration, testing, and deployment.

Run `npm run dev` for the Vite server, `npm run build` for a production bundle, `npm run lint` for static checks, and `npm run test:e2e` for desktop/mobile browser tests.

The development server proxies `/api` to port 5000. Set `VITE_API_URL` only when connecting to a separate API origin.
